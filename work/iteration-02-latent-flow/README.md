# Итерация 02 — Латентный поток (ветер)

## Общая идея
Мир «привыкает» к часто используемым направлениям, добавляя тонкий векторный сдвиг движения — едва ощутимый «ветер», выстраивающий привычные траектории.

Связь с общим курсом: игрок не видит чисел, но чувствует, что «там легче течь» после успехов.

## Что делаем
- В `src/field.ts`:
  - Добавить карты `flowX: Float32Array`, `flowY: Float32Array` и глобальное мягкое затухание `flowDecay`.
  - Накапливать поток на основе усреднённых направлений движения агентов по тайлам.
- В `src/agents.ts`:
  - Внести влияние: `velocity += k_flow * (flowX, flowY)` (параметр `flowInfluence`).
- В `src/render.ts`:
  - Тонкая визуализация вектора (редкая сетка штрихов/стрелок, низкая альфа) для отладки и как «подмигивание».

## Критерии готовности
- После длительного движения в одном направлении путь становится «липче»; статистически агенты чаще поддерживают курс.
- Влияние слабое по умолчанию, но заметное в A/B сценах.
- Нет артефактов/запираний: предусмотрено затухание и ограничение амплитуды.
