# Итерация 03 — Генератор микрозадач (без текста)

## Общая идея
Короткие ритуалы на 30–90 секунд: удержать тишину, соединить пятна, погасить шум. Подсказки — тонкие контуры/пульсации/тихий колокольчик.

Связь с общим курсом: игрок учится языку мира через действия, а не меню.

## Что делаем
- В `src/main.ts`:
  - Планировщик задач: FSM, выбор типа цели по текущему состоянию поля/плотности.
  - Метрики завершения и таймеры, 1–2 одновременные цели максимум.
- В `src/field.ts`:
  - Утилиты метрик: покрытие |v|>τ по маске, «тишина» (|v|<τ), поток через сечение.
- В `src/render.ts`:
  - Визуальные подсказки: едва заметные контуры областей/сечений; вспышки при прогрессе.

## Критерии готовности
- Две базовые задачи работают: «соединить два узла потоком N сек» и «погасить область до |v|<τ M сек».
- Подсказки минималистичны и не мешают.
