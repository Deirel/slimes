# Итерация 01 — Скрытая эхо‑память поля

## Общая идея
Закладываем фундамент «скрытого развития»: поле запоминает недавние контуры едва заметным слоем памяти. Игрок ощущает, что повторяемые паттерны «схватываются» — сенсоры агентов начинают их чуть «узнавать».

Связь с общим курсом: прогресс без чисел — через ощущаемые микросдвиги сенсинга.

## Что делаем
- В `src/field.ts`:
  - Добавить карту `memory: Float32Array` того же размера, что поле.
  - Мягкое экспоненциальное затухание памяти по времени (параметр `memoryDecay` 0..1).
  - Актуализация памяти от «успешных» паттернов: при устойчивых градиентах/потоке слегка усиливать `memory`.
- В `src/agents.ts`:
  - Сенсоры считывают `values + epsilon * memory` (параметр `memoryInfluence`).
- В `src/render.ts`:
  - Едва заметные мерцания/подсветка мест с повышенной `memory` (очень сдержанно, без HUD‑иконок).

## Критерии готовности
- При повторном проведении тем же паттерном агенты статистически чаще удерживают курс вблизи траекторий (замер через контрольную сцену).
- Визуально/аудиально — тонкий сигнал при росте `memory` (без чисел/баров).
- Производительность: не ниже базовой (используем 8‑битное хранение/тайловый апдейт при необходимости).

## Примечания
- Хранение `memory` можно начать с Float32, позже оптимизировать до 8‑бит с LUT.
