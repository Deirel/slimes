# Итерация 09 — Глобальные мягкие смещения

## Общая идея
После ритуалов/успехов глобальные параметры поля чуть пульсируют или смещаются (дыхание поля, анти‑симметрия, накопитель поворотов) — создавая «странно‑увлекательный» ритм.

## Что делаем
- В `src/main.ts`:
  - Контроллер глобальных эффектов с плавной эксп. склейкой параметров.
- В `src/field.ts`:
  - Глобальные оффсеты/модуляции диффузии/испарения/знака с малой амплитудой.

## Критерии готовности
- Периодические микросдвиги ощущаются как «дыхание», не мешая контролю.
