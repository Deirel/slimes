# Итерация 07 — Ритуалы и распознавание простых глифов

## Общая идея
Повторение S/∩/O‑подобных штрихов распознаётся как «ритуал», временно сдвигающий скрытые коэффициенты (нейрогель, дыхание поля).

## Что делаем
- В `src/main.ts`:
  - Лёгкий распознаватель шаблонов на основе траектории кисти/потока (простые дескрипторы формы).
  - Таймерные бусты скрытых слоёв (`memoryInfluence`, `flowInfluence`) на 10–60 секунд.

## Критерии готовности
- Отдельные ритуалы стабильно распознаются без ложноположительных.
- Эффект ощущается, но не ломает баланс (скромные коэффициенты, плавная склейка).
