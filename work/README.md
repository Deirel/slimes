# Рабочие итерации: Скрытое развитие колонии

Назначение папки `work/`: последовательная реализация итогов из `BRAINSTORM-IMPLICIT-COLONY.md`. Каждая итерация содержит:
- Идею (как это поддерживает общий курс «скрытого развития»)
- Технические задачи (концептуально и конкретные точки интеграции в код)
- Метрики/критерии готовности (на уровне поведения системы, без дат/оценок сложности)
- Примечания по UX/аудио‑визуальным сигналам (только суть)

Сводка итераций:
- iteration-01-memory: скрытая карта памяти `memory` и мягкое затухание
- iteration-02-latent-flow: латентный поток `flowX/flowY` и влияние на шаг агентов
- iteration-03-micro-goals: генератор микрозадач без текста
- iteration-04-rewards: незаметные «награды» (понижение шума/испарения локально)
- iteration-05-subtle-feedback: сдержанные аудио/палитровые подсказки
- iteration-06-cohesion: когезия/снижение шума поворота в кластерах
- iteration-07-rituals-recognition: ритуалы/глифы (распознавание простых форм)
- iteration-08-structural-channels: каналы/капиллярность/синапс‑мостики
- iteration-09-global-biases: глобальные мягкие смещения («дыхание поля», анти‑симметрия)
