# Прогресс разработки

Этот документ фиксирует фактические изменения по итерациям из папки `work/`.

## 2025-08-09 — Итерация 01: Скрытая эхо‑память поля
- Добавлено: скрытый слой памяти `memory` в `src/field.ts` с функциями `depositMemory(...)` и `decayMemory(...)`. Память имеет мягкую сатурацию и экспоненциальное затухание.
- Интеграция в агентов: сенсоры читают `values + memory * memoryInfluence`, агенты помимо основного следа откладывают слабый «эхо»-депозит в `memory` (`src/agents.ts`).
- Визуализация: очень сдержанное мерцание в местах высокой `memory` для перцептуальной подсказки, без явных индикаторов (`src/render.ts`).
- Параметры: в `SimParams` добавлены `memoryInfluence`, `memoryDepositFactor`, `memoryDecayPerSecond` (`src/types.ts`). В `src/main.ts` заданы стартовые значения и вызывается `field.decayMemory(...)` в подшаге цикла.
- Сброс сцены очищает и поле, и память через `clearValues()`.

Доработки итерации (баланс):
- Инструмент «Отталкивание» оставляет кратковременную отрицательную память, чтобы проще разрывать плотные «магистрали» (`main.ts` + `field.ts:addMemoryCircle`).
- Ослаблено влияние памяти и ускорен её распад для снижения инерции маршрутов: `memoryInfluence=0.2`, `memoryDepositFactor=0.25`, `memoryDecayPerSecond=0.08` (`main.ts`).

Ключевые параметры (текущий баланс):
- `memoryInfluence`: 0.2 — вес памяти в сенсорах
- `memoryDepositFactor`: 0.25 — доля депозита, уходящая в память
- `memoryDecayPerSecond`: 0.08 — скорость затухания памяти

Ожидаемый эффект: лёгкое «узнавание» недавно стабилизированных узоров и мягкая поддержка траекторий без явных HUD-индикаторов.

## 2025-08-09 — Итерация 02: Латентный поток (ветер)
- Добавлены карты векторного потока `flowX/flowY` в `src/field.ts`, с функциями `depositFlow(...)` и `decayFlow(...)`. Поток мягко распадается и клэмпится по модулю, предотвращая «запирание».
- Интеграция в агентов (`src/agents.ts`): скорость агента усиливается слабо в направлении локального потока (`velocity += flow * flowInfluence`), а фактическое движение «импринтит» направление обратно в карты потока.
- Параметры (`src/types.ts` + `src/main.ts`): добавлены `flowInfluence`, `flowDepositPerSecond`, `flowDecayPerSecond`, `flowMaxMagnitude`; стартовые значения подобраны для эффекта «едва ощутимого ветра».
- Цикл симуляции (`src/main.ts`): на каждом подшаге вызывается `field.decayFlow(...)` аналогично затуханию памяти.

Ключевые параметры (текущий баланс):
- `flowInfluence`: 0.4 — вес вектора потока в скорости агента
- `flowDepositPerSecond`: 0.9 — скорость накопления потока из движения
- `flowDecayPerSecond`: 0.12 — скорость распада потока
- `flowMaxMagnitude`: 2.0 — ограничение амплитуды потока на тайл

Ожидаемый эффект: после продолжительного движения по коридору траектория становится «липче», агенты легче поддерживают курс; эффект накапливается незаметно и самозатухает без артефактов.

## 2025-08-09 — Итерация 03: Генератор микрозадач (без текста)
- Добавлен планировщик микрозадач `GoalPlanner` (`src/goals.ts`). Реализованы два типа:
  - «Соединить два узла» (`connect_nodes`): выбирает две точки с высоким «отзывом» (по `values/memory/flow`) и требует удерживать направленный поток вдоль линии между ними в течение N секунд.
  - «Тишина в области» (`silence_area`): выбирает область и засчитывает прогресс, когда средний |values| ниже порога в течение N секунд.
- Подсказки: деликатные контуры и линия‑указатель рисуются поверх сцены без HUD‑чисел (мерцание по фазе). Интеграция в цикл рендера через `src/main.ts` (функция `drawOverlay(...)`).
- Баланс/тайминги (начальные):
  - Время на задачу: 35–90 c; требуемая выдержка: 14 c (тишина), 18 c (соединение узлов).
  - Порог тишины: среднее |values| < 0.05; критерий коридора: усреднённая проекция локального `flow` на направление линии > 0.12.
- Визуальная сдержанность соблюдена: никаких новых элементов HUD, только тонкие пульсирующие намёки поверх канвы.

Затронутые файлы:
- `src/goals.ts` — новый модуль планировщика и логики прогресса.
- `src/main.ts` — инициализация планировщика, вызов `goals.update(...)`, отрисовка намёков поверх рендера.
