# Итерация 05 — Сдержанная обратная связь (звук/палитра)

## Общая идея
Сигналы прогресса выражаются микро‑сдвигами палитры и звука, а не цифрами. «Мир подмигивает», когда игрок попал в резонанс.

## Что делаем
- В `src/render.ts`:
  - Небольшие оттеночные сдвиги гаммы при росте скрытых ресурсов (`memory`, когезия, успех задач).
- В `src/hud.ts`:
  - Опциональная строка‑мантра на порогах («Колония дышит ровнее») без чисел.
- Аудио (если есть): короткие полутоновые изменения при событиях.

## Критерии готовности
- Сигналы ощутимы, но не доминируют и не превращаются в явный HUD.
